Where a value comes from

The final design for make-value-sources-clear. Every field says where its value comes from, at rest, in one short phrase at the right of its label. That phrase is the control that changes it. Frames are 468 px wide, the dialog's width in Canvas, drawn with the dialog's tokens (the theme's slate and blue scales through --seo-*) and its four type sizes. Before frames redraw today's dialog from the audit of site-4 on 2026-11-24.

Signals are counted as in the audit: every mark at rest that says where a value comes from, or is a way in to change it. A box is not counted. Before is “at rest / with hover”. After has no hover-only cue. The most on one field: 7 today, 1 here.

1. One source control per fieldAt the right of the label row, always visible, in words. Blue with the link glyph when the value is filled from the item; gray when it is set in SEO settings. A field with only one possible source has none.
2. A box means you type hereText kept at this scope sits in an input box. Everything else, and every value that follows something, is a read-out: the value in ink, with no box.
3. One menu, grouped by follows and setFollows each Article (or the page), follows the site or another language, and Set for every Article (or on this page). Link, unlink, go back, override: pick a row.
