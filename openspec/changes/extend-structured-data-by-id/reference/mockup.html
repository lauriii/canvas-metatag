F10

Invalid JSON: the Form tab explains

The Form tab always switches. With unreadable text it shows one notice with the one fix and "Go to line", never a half-form. There is no automatic repair preview: each problem carries its own fix, and a pasted script tag, @context or @graph left in carries "Clean up".
