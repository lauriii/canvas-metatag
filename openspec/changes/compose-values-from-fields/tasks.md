# Tasks

## Conventions

Test paths:

- unit tests in `tests/src/Unit/`, kernel tests in `tests/src/Kernel/`;
- vitest next to the source in `extension/src/`;
- Playwright in `tests/e2e/`.

Run PHPUnit through the farm's `docker exec` with the sqlite test database.
Run one browser suite at a time. Browser checks run on the farm site
(site-4), signed in as an editor unless a task says administrator.
Screenshots go on the merge request.

Where a test is meant to fail before the fix, commit it first and record the
failure in the merge request. Phases 2 to 4 each end releasable.

The composer's behaviour lives in a real browser, so it is proved in
Playwright. Vitest covers the model: joining, words, canonical form, state
sentences, Checks.
